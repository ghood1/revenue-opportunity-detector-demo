About This Demo
How the demo build differs from the production tool
🧪
This is a demo build. Everything you see runs locally in your browser on fictional sample data. There are no API credentials, no outbound requests, and no connection to any live system. Buttons that would normally write to a CRM simulate their result instead.
Who built this
I built this after spending too long manually pulling reports to work out which properties in the portfolio were quietly underperforming — and then still not knowing which ones were worth acting on first. The tool does both parts: it finds the problem and it sizes it in pounds, so the list sorts by what is actually worth someone's time. I wrote the warehouse SQL, the detection logic, the scheduled pipeline, the CRM integration and this interface.
— Greg Hood
In the production build
1A scheduled workflow queries the data warehouse for per-property booking value, occupancy, ADR and cancellation history across a rolling 12-month window.
2Pricing and market benchmarks are layered on to establish what each property should be earning versus comparable local listings.
3A detection pass flags each property against six signals and sizes the recoverable revenue behind every flag.
4Flagged properties are matched to their account manager and host record in the CRM, so a task or host email can be raised in one click.
